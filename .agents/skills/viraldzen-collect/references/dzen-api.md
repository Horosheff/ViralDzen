# Ручки Дзена и как сборщик ими пользуется

Читай этот файл, если чинишь `viraldzen` или ручка отвалилась. Для обычной смены хватает CLI из SKILL.md.

Официального API «вирусных статей» нет. Вирусное сидит в рекомендациях: статья по теме → вниз → офферы. Браузер не нужен.

Логин в Яндекс не нужен. Гостевые cookies — `data/cookies.txt`, в git не коммитить.

## Эндпоинты

| Задача | Как |
| --- | --- |
| Официальные хабы | `GET https://dzen.ru/api/web/v1/zen-search?forced_request_type=topic_channel_search&type_filter=topic_channel&query=...` |
| Поиск статей/постов | тот же host, `forced_request_type=media_search`, `type_filter=brief,article` |
| Пагинация поиска | `feedData.more.link` или `more.link` |
| Лента рекомендаций | `GET https://dzen.ru/api/v3/launcher/export` и `.../more` |
| Канал | тот же `export` с `channel_name=` или `channel_id=` |
| Полный текст, обложка, картинки | HTML `https://dzen.ru/a/{id}` → JSON `ssrData.publishersResponse` (Draft.js) |
| «Офферы» вокруг материала | поиск `тема + слова из заголовка` + лента канала автора (`recirc`) |

Клиент: `viraldzen.http.DzenClient` — urllib, `--delay`, ретраи. Не подменять Playwright, пока это живое.

Разбор канала (`viraldzen channel`): лента `export` → теги/слова из карточек и SSR → поиск официальных хабов по этим словам. Сбор после канала по умолчанию идёт **по теме на всём Дзене**, не «только посты этого канала». Если человек просит вирусное именно с этой ленты — `--channel-only`.

## Что делает `collect`

1. Прогреть cookies.
2. Резолв официального хаба, разбор канала/статьи, `--raw-topic` или `--channel-only`.
3. `zen-search` по названию темы.
4. Опционально лента `export`, только `matches_topic`.
5. Скор, top-N.
6. Recirc: семена → доп. поиск и канал автора. Кликбейт и оффтоп отбрасываются.
7. SSR текст и картинки, пересчёт скора.
8. Картинки, SQLite + CSV + HTML.

`source_kind`: `search`, `feed`, `recirc`, `channel`.

## Скор и флаг `is_viral`

Просмотры важнее шумного ER на маленькой выборке. Дальше дочитывания, лайки, комментарии, свежесть.

`is_viral`: выброс по просмотрам, верхний квартиль скора при живом охвате, высокий ER или сильное дочитывание. Кликбейт-тесты режет `parse.is_clickbait`. Флаг ещё и относительный к текущей выборке: в маленьком top-N почти все будут с флажком. Человеку важнее `views`. Тема матчится по слову и склонению (`здоровье` ≈ `здоровья`), но не по «здорово».

## CLI, о который агенты спотыкаются

- Без TTY нужны `--topic` / `--slug` / `--channel` / `--url`. Не зависай на `input()`.
- `--url` — канал, статья `dzen.ru/a/…` или хаб `dzen.ru/topic/…`.
- `--channel-only` — скор и HTML по ленте этого канала, без поиска по всему Дзену.
- Несколько `--topic` без `--pick` в неинтерактиве: для каждого запроса главный хаб.
- `--channel` без `--pick`: берёт `--channel-limit` хабов (по умолчанию 3) и **печатает предупреждение**. Для агента лучше сначала `channel`, потом `--pick`.
- Узкая фраза без хаба — `--raw-topic`.
- Главный файл для человека — `viral.html`. На `collect` можно сразу `--portable`.
- Юниты без сети: `python3 -m unittest discover -s tests -v`.

## Если ручки сменили форму

Сними JSON с `zen-search` / `export` / SSR, сравни с `viraldzen/parse.py`. Поправь парсер и тест, не пиши новый клиент.
