## 💡 Что это такое и зачем нужно?

Писать в Дзен «по вдохновению» — это круто, но долго и рискованно: можно потратить неделю на текст, который никто не откроет. 

**ViralDzen** — это ваш личный радар вирусных тем. Он работает как «рилсы на миллион», только для текстовых статей в Дзене. Вы задаёте тему (или скармливаете ссылку на канал конкурента), а инструмент находит материалы, которые **рекомендательная система Дзена уже раскрутила на огромную аудиторию**.

### 🔥 Главные преимущества

- **⚡ Без браузера и тяжёлых эмуляторов**: Никаких Selenium, Playwright или Chrome. Работает молниеносно через прямые легковесные HTTP-запросы к публичным данным Дзена.
- **🔒 Без логина и паролей**: Не нужно авторизоваться в Яндексе или рисковать аккаунтом — анализируются только открытые публичные материалы.
- **📦 Ноль сторонних зависимостей (Zero Dependencies)**: Написан на чистом Python (стандартная библиотека). Установка не требует тонн внешних библиотек.
- **🎯 Честный алгоритм виральности**: Отсеивает накрутки и кликбейт («пройди тест на возраст»). Главный приоритет — реальные просмотры, дочитывания до конца и глубина вовлечения.
- **🖥️ Красивая интерактивная витрина `viral.html`**: Результат сбора — готовая страница с обложками, текстами, фильтрами, сортировкой и чтением статьи в один клик.
- **🤖 Рождён для ИИ-агентов (Agent Skills)**: Идеально интегрирован с **Cursor**, **Claude Code**, **Codex** и другими агентными средами.

## 🧠 Как это работает простыми словами

У самого Дзена нет кнопки «покажи статьи с максимальным охватом». Вся магия спрятана под капотом:

1. **Официальные хабы тем**: Дзен группирует контент по темам с миллионами подписчиков (`dzen.ru/topic/...`). Вы пишете слово (например, *«психология»* или *«сад и огород»*), а ViralDzen находит официальные разделы и показывает точное число подписчиков.
2. **Сбор ленты и офферов (Recirc)**: Когда читатель открывает успешную статью, внизу Дзен подгружает бесконечную ленту похожих материалов («офферы»). Скрипт идёт туда и вытягивает самые раскрученные публикации.
3. **Анализ канала или статьи**: Если прислать ссылку на канал конкурента (`dzen.ru/<имя>`) или конкретную статью (`dzen.ru/a/<id>`), инструмент сам поймёт главные темы и найдёт релевантные вирусные публикации.
4. **Ранжирование**: Каждая статья получает `viral_score`. Отдельный флаг `is_viral` выделяет настоящие аномалии просмотров в текущей нише.

## 🤖 Способ 1. Для всех: запуск через ИИ-агента (Cursor, Claude Code, Codex)

Если вы работаете в редакторе с ИИ-агентом, вам даже не нужно вникать в команды терминала. Агент сделает всё сам.

### Шаг 1. Подключите репозиторий или скилл

**Вариант А — открыть проект в Cursor:**
Просто склонируйте репозиторий и откройте его как рабочую папку в Cursor. Скилл `viraldzen-collect` подхватится автоматически:
```bash
git clone https://github.com/Horosheff/ViralDzen.git
```

**Вариант Б — установить скилл глобально в любой свой проект:**
```bash
# Через npx:
npx skills add Horosheff/ViralDzen

# Или через GitHub CLI:
gh skill install Horosheff/ViralDzen --agent cursor --scope user
```

**Вариант В — из клона одной командой:**
```bash
./install-skill.sh
```

---

### Шаг 2. Отправьте готовый промпт агенту

Скопируйте этот текст в чат агента, указав свою тему или ссылку:

```text
Найди вирусные статьи в Яндекс Дзене по теме: [НАПРИМЕР: ЗДОРОВЬЕ / РЕЦЕПТЫ / ИЛИ ССЫЛКА НА КАНАЛ].
Инструмент: https://github.com/Horosheff/ViralDzen

1. Сначала через python3 -m viraldzen topics найди официальные хабы по моим словам и покажи их с числом подписчиков.
2. Подожди, пока я выберу номер подходящего хаба.
3. Запусти сбор (collect) по выбранной теме с задержкой --delay 0.7.
4. В конце пришли мне путь к файлу viral.html и покажи топ-5 самых просматриваемых заголовков с цифрами.
```

> 🎯 **Результат:** Агент покажет вам официальные темы, дождётся вашего выбора, сам соберёт данные и отдаст готовую интерактивную витрину `viral.html`.

## 💻 Способ 2. Для разработчиков: запуск через терминал (CLI)

Требуется **Python 3.11+**. Сторонние пакеты ставить не нужно!

### Установка CLI

Из склонированного репозитория команды запускаются напрямую:
```bash
python3 -m viraldzen -h
```

Либо можно установить пакет в систему через pip:
```bash
pip install "git+https://github.com/Horosheff/ViralDzen.git"
```

---

### Основные сценарии использования

#### 1. Поиск по теме словами

```bash
# 1. Посмотреть официальные хабы Дзена с числом подписчиков:
python3 -m viraldzen topics --query "здоровье"

# 2. Собрать вирусные статьи (выбираем хаб №1):
python3 -m viraldzen collect --topic "здоровье" --pick 1 --pages 2 --top 20 --out-dir data --delay 0.7

# Или сразу напрямую по известному slug темы:
python3 -m viraldzen collect --slug zdorove --out-dir data --delay 0.7
```

#### 2. Анализ по ссылке на канал конкурента

```bash
# Узнать, о чём канал, и увидеть похожие темы:
python3 -m viraldzen channel --url "https://dzen.ru/<имя_канала>"

# Собрать вирусные материалы по главным темам этого канала:
python3 -m viraldzen collect --channel "https://dzen.ru/<имя_канала>" --channel-limit 3 --out-dir data --delay 0.7

# Собрать вирусное ТОЛЬКО из ленты самого этого канала:
python3 -m viraldzen collect --channel "https://dzen.ru/<имя_канала>" --channel-only --out-dir data --delay 0.7
```

#### 3. Анализ по ссылке на конкретную статью или хаб

```bash
# Разобрать статью и найти похожие вирусные публикации вокруг неё:
python3 -m viraldzen collect --url "https://dzen.ru/a/<id_статьи>" --out-dir data --delay 0.7

# Сбор по прямой ссылке на хаб:
python3 -m viraldzen collect --url "https://dzen.ru/topic/zdorove" --out-dir data --delay 0.7
```

#### 4. Просмотр результатов в консоли и экспорт

```bash
# Вывести красивую текстовую таблицу в терминал:
python3 -m viraldzen table --db data/viral.sqlite --limit 20

# Экспортировать в CSV (UTF-8 с BOM, открывается в Excel без кракозябр):
python3 -m viraldzen export --db data/viral.sqlite --csv data/viral.csv

# Пересобрать HTML-витрину (или объединить базы нескольких сборов в один дашборд):
python3 -m viraldzen html --db data/viral.sqlite --out data/viral.html
python3 -m viraldzen html --db data/tech.sqlite --db data/auto.sqlite --out data/all.html --title "Сводка трендов"
```

## 📊 Что вы получаете на выходе

Все собранные данные сохраняются в папку `data/` (она автоматически добавлена в `.gitignore`, чтобы ваши выгрузки не попали в публичный репозиторий).

| Файл / Каталог | Что это такое | Для чего использовать |
| :--- | :--- | :--- |
| **`data/viral.html`** | 🌟 **Главный результат** — интерактивная веб-витрина | Открыть в браузере. Есть живой поиск, сортировка по колонкам, фильтры, показ обложек и кнопка **«Текст»** для мгновенного чтения статьи. |
| **`data/viral.sqlite`** | База данных SQLite | Локальное хранилище со всеми сырыми полями, тегами, текстами и метриками. |
| **`data/viral.csv`** | CSV-файл (UTF-8 BOM) | Удобно загрузить в Excel, Google Таблицы или Notion для контент-плана. |
| **`data/images/<id>/`** | Локальные картинки | Скачанные обложки и иллюстрации из статей в оригинальном разрешении. |

> 📱 **Режим `--portable`:** Если вы хотите переслать HTML-файл коллеге или открыть его без папки `images/`, запускайте сбор с флагом `--portable` (картинки будут подгружаться напрямую с серверов Дзена).

## 📐 Как устроен скоринг виральности

В отличие от примитивных парсеров, ViralDzen не верит только лайкам: на маленьких каналах 10 лайков от друзей могут дать ложный «высокий ER».

Формула `viral_score` учитывает:
1. **Просмотры (`views`)** — главный вес (логарифмическая шкала).
2. **Дочитывания (`read_through`)** — отношение дочитавших до конца к открывшим статью.
3. **Скорость набора (`velocity`)** — отношение просмотров к возрасту материала.
4. **Обоснованное вовлечение (`trusted ER`)** — лайки и комментарии только при наличии репрезентативного охвата.
5. **Фильтр кликбейта**: Заголовки типа *«Если вы ответите на 8/10 вопросов...»* или *«Вся правда о...»* автоматически пессимизируются коэффициентом **0.35**.
6. **Метка виральности (`is_viral`)**: Флаг `*` получают материалы, ставшие статистическими выбросами (в 3+ раза выше медианы по просмотрам, либо входящие в топ-25% общего рейтинга).

## 🛠️ Под капотом: откуда берутся данные

ViralDzen эмулирует поведение клиента Дзена через официальные открытые JSON-ручки:

| Задача | Эндпоинт Дзена | Описание |
| :--- | :--- | :--- |
| **Поиск официальных хабов** | `GET /api/web/v1/zen-search?forced_request_type=topic_channel_search...` | Находит подтверждённые хабы тем и число читателей |
| **Поиск статей по теме** | `GET /api/web/v1/zen-search?forced_request_type=media_search...` | Выгружает статьи и посты по ключевым запросам |
| **Рекомендательная лента** | `GET /api/v3/launcher/export` | Забирает текущие рекомендации платформы |
| **Лента канала** | `GET /api/v3/launcher/export?channel_name=...` | Полный срез публикаций конкретного автора |
| **Полный текст и медиа** | SSR JSON на странице `dzen.ru/a/{id}` (Draft.js) | Забирает структурированный текст без рекламных блоков |
| **Подборка офферов (recirc)** | Уточняющий поиск и рекомендации вокруг статьи | Находит смежные популярные материалы |

## ⚙️ Продвинутый режим (пакетный сбор по конфигу)

Если вам нужно регулярно мониторить десятки разных ниш, создайте `topics.json`:

```bash
cp topics.example.json topics.json
```

Пример `topics.json`:
```json
{
  "topics": ["финансы", "инвестиции", "недвижимость"],
  "pages": 2,
  "top_n": 30,
  "min_views": 5000,
  "delay_seconds": 0.7,
  "portable": true
}
```

Запуск пакетного сбора:
```bash
python3 -m viraldzen collect --config topics.json --out-dir data
```

## 🛡️ Важные правила и этика сбора

- **Задержка запросов (`--delay`)**: По умолчанию установлена разумная пауза `0.7 сек`. Не отключайте задержку, чтобы не перегружать публичные сервера Дзена.
- **Авторские права**: Собранные тексты и формулы заголовков предназначены для **анализа трендов, поиска вдохновения и глубокого рерайта**. Никогда не копируйте чужие статьи целиком.
- **Конфиденциальность**: В репозитории нет чужих ключей или cookies. Данные выгружаются локально в ваш каталог `data/`.
