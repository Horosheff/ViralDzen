# Шаблон `handoff.md`

Пиши коротко, по факту. Файл локальный, в git не коммить.

```markdown
# Handoff

- Цель:
- Статус: готово | частично | блокер
- Как выбрали: тема словами | канал | статья | хаб
- Канал (если был): URL · имя
- Тема: номер (если был) · название · slug · подписчики · URL хаба
- Как искали: официальный хаб | raw_topic | канал по всему Дзену | только лента канала
- Команда:
- HTML (главное для человека):
- Пути: CSV · SQLite · картинки
- Строк: N, с полным текстом: M, is_viral: K
- Топ по просмотрам:
  1. заголовок — views
  2.
  3.
- Блокер (если есть): что сломалось и что уже пробовали
```
